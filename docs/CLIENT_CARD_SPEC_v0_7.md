# First Client Card — staging specification

The first client-facing property card should show:
- Property / unit identity.
- Purchase price and source-status label.
- TAC.
- Net Yield and whether income is ACTUAL / MARKET DATA / DEVELOPER MODEL / PP ESTIMATE.
- PP Investment Score and Risk only when calculation inputs exist.
- Data Confidence.
- Verdict status: FINAL / PROVISIONAL / BLOCKED.
- Why Buy / Why Not Buy.
- Scenario assumptions.
- Calculation date + methodology version.

For Layan Verde staging, the card must explicitly say that THB 749,745 annual owner income comes from a DEVELOPER MODEL. It must not be described as realized historical NOI.
