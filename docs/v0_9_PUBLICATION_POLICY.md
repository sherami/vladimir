# v0.9 Publication Policy

A public recommendation is now a frozen snapshot containing:
1. exact immutable calculation run;
2. analyst narrative;
3. source disclosures;
4. scenario disclosures;
5. property identity.

Publish is rejected if Why Buy / Why Not Buy / Summary are missing.

Narrative does not alter financial calculations. It explains them.

The Layan Verde narrative JSON included in staging is an example analyst draft based on the currently classified inputs. It is not automatically promoted to production truth.
